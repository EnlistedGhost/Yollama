## Welcome!
Thank you for taking the time to read this documentation of Yollama! <br />
Yollama is a fork of Yollama that is geared directly for "no frills" and "extreme privacy". 

Currently, Yollama has many back-door connections, hidden remote servers, and many other aspects of the system that are far from "local only" model running. Yollama (stands for Ex-Yollama) aims to remedy this farce that Yollama peddles to their users.

Far from secure, Yollama enacts many hidden and not-made-public aspects of their program that hinders a user's ability to guide and run an LLM AI model to the point or aspect that they desire. This project aims at taking back control for the user, ensuring there are no Automated-Updates, Remote-connections, and no other aspects that could possibly cause a local-only runtime from affecting the user of this project.
