## Welcome!
Thank you for taking the time to read this documentation of Yollama! <br />
Yollama is a fork of Ollama that is geared directly for "no frills" and "extreme privacy + security" as its main focus. 

Currently, Ollama has many back-door connections, hidden remote servers, and countless other aspects of the system that are far from "local only" model running. This project, Yollama, (stands for Your-Yollama) aims to remedy this farce that Ollama forces onto their users.

Far from secure- Ollama enacts many hidden and not-made-public aspects of their program that hinders a user's ability to guide and run an LLM AI model to the point or aspect that they desire. This project aims at taking back control for the user, ensuring there are no Automated-Updates, Remote-connections, Remotely defined and used "Model-Suggestions", and no other underlying operations that could possibly cause a supposed "local-only" runtime from affecting the user of this project. 

Yollama also compiles much faster! Having stripped away the bloat, Yollama does not include a UI, MLX-Runner, Useless Proprietary Templates, or "APP" (LLM-server and model-runner are the focus). With all of the hidden network outreach and remote overrides affecting the code now gone from the source- users will no longer see AI inference quality wildly variate as they use this software, nor will a user see the AI responses simply fail when disconnecting from their network (try it with Ollama... Load a model and then disconnect from the network during any portion of it attempting to respond back to you! The response will fail!). This project also boasts faster compile times, such as a blazing ~30 seconds using most any modern CPU (anything Core-i7 10th gen and higher). As an example: Using an Intel Xeon Silver 4216, this project compiled within 1-minute.
